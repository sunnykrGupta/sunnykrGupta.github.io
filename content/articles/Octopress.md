### Deployment of Octopress : Blog Frameworks for Hackers

Octopress is a static blogging framework built on top of Jekyll. It uses scripts to build static files to be deployed to a server. You can design your blog and deploy on [Github-Pages](https://pages.github.com/) very quickly.

#### Installation's :
 - Git
 - Jekyll
 - Ruby Gem

How to setup Octopress?? [Go ahead](http://octopress.org/docs/setup/).

Variety of theme available [here](https://github.com/imathis/octopress/wiki/3rd-Party-Octopress-Themes).
